# Global Relief Consult (GRC) Web Application

A modern, high-performance web application for **Global Relief Consult (GRC)**, built with Next.js 16 (App Router), React, TypeScript, and Vanilla CSS.

## Overview

Global Relief Consult organizes and manages global events, trains, empowers, and deploys projects and programmes under Sustainability, ESG, CSR, M&E, and specializes in Empowerment Training Programmes, Leadership Trainings, Skills Acquisition, Capacity Building, and Content Development.

## Features & Pages

- **Home (`/`)**: Hero Slider with automated smooth transition, Welcome Section with authentic 3-photo collage, Quote Section with leadership avatar, interactive Gallery Accordion, and Contact CTA.
- **Who We Are (`/who-we-are`)**: Complete scope, global footprints, supported entities, needs assessment, ESG disclosure, and 2-column Vision & Mission layout.
- **What We Do (`/what-we-do`)**: UNSDG 13-item focus areas, Girls in ICT & STEM, Interventions, Target Group, Diversity & Inclusion, and 4 funfact stat counters.
- **The Leadership (`/our-team`)**: All 13 leadership profiles and 2 advisory board member photo cards with authentic credentials.
- **Gallery (`/gallery`)**: 39 authentic project and event photographs with interactive full-screen Lightbox modal.
- **Purple Petals Construction, Transport and Logistics LLC (`/purple-petals-construction-transport-and-logistics-llc`)**: 5-image background crossfade hero, full authentic copy, and 5-project architectural design portfolio.
- **Warehouse & Storage Management (`/warehouse-storage-management`)**: 2-image background slideshow hero, authentic copy with 5 core solution features, support services, and dual distribution photo cards.
- **Deep Dream (`/deep-dream`)**: Archivo watermark header, comprehensive creative studio copy, and 11-photo studio equipment & facilities gallery.
- **Brave Heart (`/brave-heart`)**: Archivo watermark header, authentic Montessori and childcare copy (Transport Program, After School Program, Additional Services), and 30-photo campus & playground gallery with interactive Lightbox.
- **Contact Us (`/contact-us`)**: Dedicated contact channels, office locations, and direct inquiry form.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS with curated CSS variables (no Tailwind CSS)
- **Typography**: Google Fonts (Roboto, Archivo, Poppins, Playfair Display)
- **Image Optimization**: `next/image` with responsive `sizes` and priority loading

## Getting Started

### Prerequisites

- Node.js 18.18+ or Node.js 20+
- npm or yarn

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3001](http://localhost:3001) in your browser.

### Building for Production

```bash
npm run build
npm start
```
